## 저장·검색 구조

- `data/nutrition/manifest.json`: 전체 건수, 원본 SHA-256, 버전, 인덱스·분할 데이터 체크섬.
- 데이터셋별 `index.json.gz`: 이름·식품코드·제조사·분류 검색용 인덱스.
- `part-0000.json.gz` 등의 파일: 1,000개 레코드 단위. `columns`와 희소 `rows`로 원본 열과 제공값을 모두 보존합니다. 없는 값은 생성하지 않습니다.
- `food-data.html`: 별도 영양·제품 검색. 검색은 Web Worker에서 수행하고, 상세 조회 시 필요한 분할 파일만 불러옵니다.
- `data-status.html`: 완료·차단·미수집을 구분한 현황. JavaScript 없이도 확인 가능합니다.

영양 기준량·식품중량·1회 섭취참고량을 구분해서 표시합니다. 원본 문자열·단위·0·날짜를 보존하고 영양값을 임의 환산하지 않습니다. 이름이 유사한 제품·음식을 레시피에 자동 병합하지 않습니다.

## 활용신청 승인 후 전체 수집 완료

기존 인증키의 서비스 활용신청 승인을 확인하고 7개 공식 전체파일을 확보했습니다. CSV 인용부호 안의 쉼표 처리와 UTF-8 경계 판독을 보정하고 보관된 실원본을 API 추가 호출 없이 다시 전수 변환·검증했습니다.

I0490·I0580·I1250은 공식 전체파일 행 수와 API 참조 총건수가 다릅니다. 위 완료는 **제공된 공식 전체파일 전수 변환** 기준이며 실시간 API와 동일한 스냅샷이라고 주장하지 않습니다. 원본 파일·행 수·해시·API 참조 건수를 함께 보존합니다. C005의 원문 259,793행 중 고유 행은 259,741개이며 중복 52행도 원문대로 보존합니다.

- [성공한 재변환·전수 검증 실행](https://github.com/softm/foodhannun/actions/runs/39446554760)
- [공식 번호 연결 인덱스 생성·검증](https://github.com/softm/foodhannun/actions/runs/39448618386)
- `data/collection/{서비스}/status.json`: 수집 시각·공식 파일/API 기준·필드·전체 분할 파일 검증값.
- `data/collection/{서비스}/records-NNNN.jsonl.gz`: 원문 전체 열·값을 10,000행 단위로 보존.
- `data/food-safety/manifest.json`: 원본별 전체 검색 인덱스와 정확한 번호·원료명 조회 버킷.
- [공식 원재료·안전 자료 검색](../food-safety.html): 7종 원본 전체 검색·원문 상세.

제품 영양 자료의 품목제조보고번호로 I1250·C002·I0490·과거 C005를 연결하고 I1250 업소 인허가번호로 I0580을 연결합니다. 원료명·이명은 사용 부위·조건을 함께 확인하는 후보 탐색입니다. 회수 대상 제조분, 제품 HACCP 인증, 현재 바코드, 알레르기 안전을 이름만으로 확정하지 않습니다.

농촌진흥청 원재료성 식품 전체 파일, 국립수산과학원 원재료성 식품 성분표, 실시간 쇼핑 가격·재고, 사용자 리뷰·평점도 아직 수집되지 않았습니다. 음식·가공식품 영양 DB를 이 자료의 수집 완료로 대신 표시하지 않았습니다.

## 재수집

```bash
pip install -r scripts/requirements-data.txt
python3 scripts/sync-nutrition.py
python3 scripts/build-data-status.py
```

기존 GitHub Secret을 사용하는 추가 수집 워크플로를 수동 실행합니다. 각 서비스의 공식 전체 파일을 순차 수집하며 `reuse_source`로 보관된 원본을 API 호출 없이 재변환할 수 있습니다. 실패한 시도는 기존 정상 스냅샷을 보존하고 실제 실패 사유를 표시합니다. 인덱스 워크플로는 검증된 데이터 브랜치에만 결과를 생성합니다.

새 영양 수집 워크플로는 수동 실행·주 1회(월요일 05:35 KST) 수집본 보관으로 준비했습니다. 영양 수집 결과는 별도 보관하며 레시피 자동수집과 구분합니다. 정기 수집은 통합 워크플로로 자동화했습니다. 과거 C005를 제외한 6종과 레시피·영양은 검증 후 운영까지 자동 반영합니다. 현재 주기는 [운영 절차](DATA-COLLECTION-OPERATIONS.md)를 따릅니다.
