# 음식한눈 공통 계정·사이트별 보관소

2026-10-28. 공통 SDK 원본은 [softm.github.io](https://github.com/softm/softm.github.io/tree/main/shared/platform/v1), 운영 계정 허브는 https://softm.github.io/account/ 입니다.

저장 범위: **저장한 레시피·장보기·최근 검색·개인 메모**, 이 사이트의 개인 메모. 인증 토큰·광고 저장소·공공데이터 캐시는 포함하지 않습니다.

1. **내 보관소**에서 Google·카카오·네이버 중 로그인합니다. 네이버는 공개 검수 전 개발회원 범위입니다.
2. 별도 보관소 암호 10자 이상을 입력하고 **저장본 확인**을 누릅니다.
3. 처음에는 **현재 자료 저장**, 다른 기기는 **선택한 자료 복원** 후 **복원한 사이트 새로 열기**를 누릅니다. 첫 연결에서 기존 원격 기록을 자동으로 덮어쓰지 않습니다.
4. 저장·복원 후 자동 저장을 켜면 현재 창에서만 15초마다 변경을 검사합니다. 계정·작업공간 변경 시 멈춥니다.
5. **암호 지우고 잠그기**, **이 사이트 로그아웃**, **원격 저장본 삭제**를 제공합니다.

기기에서 AES-GCM 암호화하고 Firestore의 사용자·사이트별 경로에 불변 백업과 revision 조건부 head를 저장합니다. 최근 5개를 유지하며 충돌·잘못된 암호·불완전한 백업은 기기 자료를 덮어쓰지 않습니다. 기존 별도 Firebase/ChatGPT 계정은 자동 병합하거나 삭제하지 않습니다. 앱 전용 bridge의 복원은 기기 모드 또는 명시적인 새 프로젝트 사본을 사용합니다.

공통 코드·합성 브라우저 검사와 각 저장소의 기존 검사를 함께 사용합니다. 실제 운영 배포·실계정 로그인 검증은 CI 성공과 별도로 확인합니다. Android 외부 브라우저 인증·앱 링크·네이티브 Firebase 연결은 이 웹 연결의 검증 범위에 포함하지 않습니다.
