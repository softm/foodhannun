# 음식한눈 카카오 AdFit 운영

음식·제품 검색 흐름을 가리지 않는 콘텐츠 하단 배너 한 곳만 운영한다. PC는 728×90, 모바일은 320×100 전용 광고 단위를 사용한다. 전면·팝업·보상형 광고와 자체 새로고침은 사용하지 않는다.

## 설정

AdFit Web 매체 `음식한눈`(`NDH`, `softm.github.io/foodhannun`)에 다음 전용 단위를 발급해 `assets/adfit-config.js`에 연결했다. 다른 서비스의 단위를 재사용하지 않는다. ID가 비어 있거나 규격·가용 폭이 맞지 않으면 광고 영역을 표시하지 않는다.

| 화면 | 규격 | 광고단위 | 새로고침 |
| --- | --- | --- | --- |
| 모바일 | 320×100 | `DAN-mRT1rBpyxzzeADff` | 미설정 |
| PC | 728×90 | `DAN-D6GNl655i1ZpM3kR` | 미설정 |

광고는 화면 200px 안쪽에 들어온 뒤 한 번만 요청한다. SDK 오류, NOAD 콜백 또는 30초 안에 광고 프레임이 생성되지 않으면 빈 공간을 제거한다. `AdMobNative/1` User-Agent를 사용하는 WebView에서는 웹 광고 요청을 차단한다.

## 출시 전 확인

1. `node --test tests/adfit.test.js`를 통과한다.
2. 모바일 320px 이상과 PC 728px 이상에서 각 전용 단위를 요청하는지 확인한다.
3. 광고 차단, 느린 네트워크, NOAD에서 빈 공간이 사라지고 핵심 기능이 유지되는지 확인한다.
4. 공개 페이지의 개인정보처리방침과 카카오 개인정보 보호 안내 링크를 확인한다.
5. Android 앱은 웹 AdFit만 사용하더라도 Play Console의 `광고 포함`을 `예`로 갱신한다. 네이티브 광고 SDK와 `AD_ID` 권한이 없다면 광고 ID 사용은 별도 질문의 실제 구현대로 답한다.
6. AdFit에서 공개 URL의 광고 요청을 확인한 후 매체 심사 상태를 확인한다.
